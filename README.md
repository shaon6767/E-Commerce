# A Modern E-Commerce Platform 

A clean, modern online store frontend built to simulate a real e-commerce shopping experience. This project focuses on smooth user interactions, responsive design, and local state management.

## ✨ Features
* **Product Filtering:** Easily browse and filter through products by category.
* **Working Shopping Cart:** Add items, remove items, and update quantities with real-time total calculations.
* **Mock Checkout:** A simulated checkout flow featuring a demo payment system to mimic a real transaction.
* **Fully Responsive:** Optimized for everything from mobile screens to desktop monitors.

## 🛠️ Tech Stack
* **Library:** React
* **Styling:** Tailwind CSS
* **State Management:** Redux / React State Hooks
